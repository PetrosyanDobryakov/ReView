# ReView Desktop — план (ветка `dev-petrosyan-desktop`)

База ветки: `origin/dev-warexpor` на `fc8a518` (1.0 redesign). Дата заведения: 2026-10-17.
`dev-petrosyan` не трогаем. Сайт/Cloudflare в этой ветке не меняем без нужды.

## Решения заказчика (зафиксировано, 2026-10-17)

1. **Платформы:** Windows + Mac + Linux. Android — отложен, не проектируем под него сейчас.
2. **Сеть обязательна:** офлайн И онлайн в десктопе v1. Сетевую часть переписываем/расширяем, а не выкидываем.
3. **Дистрибуция с запасом сразу:** установщики + автоапдейт с уведомлением "доступно обновление", а не голый `.exe`.

## Зачем десктоп (что облегчаем)

Сейчас три упора (подробно — см. переписку 2026-10-17):

- **(A) IndexedDB как кэш браузера** (`review-v1-<boardId>`): чистка кэша = потеря досок, квота браузера вместо диска.
- **(B) Лимит 32 МБ** (`src/core/boardShare.ts` `MAX_BASE64_CHARS`, WS-сервер, `.review`-экспорт).
- **(C) Cloudflare `review-sync` (DO)** гоняет трафик даже для соседей по Wi-Fi + хранит комнаты + стоит денег.

Десктоп закрывает (A) полностью (файлы/SQLite), (C) на 80–90% (LAN и офлайн мимо Cloudflare),
(B) частично (потолок выше, но Yjs-док надо худеть отдельно — картинки файлами, сжатие при вставке, компактификация).

## Целевая архитектура (черновик, уточняется)

- **Оболочка:** Tauri v2 (уже заведено: `src-tauri/`, `npm run desktop`). WebView2 на Windows (= Chromium-движок),
  WKWebView на Mac, WebKitGTK на Linux. Веб-код (`dist/`) переиспользуется на 100%.
- **Хранение:** файловое — Yjs-апдейт + картинки отдельными файлами по хешу в каталоге приложения;
  IndexedDB остается скоростным кэшем. Лимит 32 МБ для локальных досок снимаем.
- **Режимы синка (все три в v1):**
  1. Офлайн (по умолчанию, все локально);
  2. LAN (хост поднимает локальный `review-sync`, гости заходят как сейчас по LAN-IP);
  3. Cloud (существующий `review-sync` DO) — только для удаленных через интернет.
- **Дистрибуция:** Tauri bundler (nsis/msi, dmg, AppImage/deb) + Tauri updater с диалогом обновления.
- **Сайт остается:** десктоп не заменяет `review.*.workers.dev`, форматы досок совместимы (`.review.json` — мост).

## Этапы (предварительно)

3. Режимы синка офлайн/LAN/Cloud + UI-переключатель + встроенный хост синка.
4. Установщики + подпись + автоапдейт + канал обновлений.
5. Нагрузочные тесты тяжелых досок (целенаправленно меряем вес/Yjs-diff/WS-трафик в Cloudflare).
