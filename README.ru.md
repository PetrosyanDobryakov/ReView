# Доска

[English](README.md) · [Русский](README.ru.md) · [中文](README.zh.md)

Локальная бесконечная доска. Маркер, стикеры, текст, картинки. Работает без сети. Совместное редактирование идёт напрямую между устройствами (P2P, WebRTC): доска хранится только у участников. Хостите сами — маленький бинарник `review-host` или десктоп-приложение. Хост раздаёт интерфейс и знакомит участников, но данные доски не хранит и не пересылает.

Репозиторий и продукт называются ReView. Имя на экране можно переименовать кликом по нему в шапке.

![Пустая доска](docs/screenshots/board.png)

## Что внутри

- Перо, хайлайтер, ластик (весь объект или кусок линии)
- Прямоугольник, эллипс, стрелка, стикер, текст
- Картинки: файл, вставка, drag-and-drop, обрезка
- Отмена / повтор, порядок слоёв, блокировка, ласо, рамка
- Сохранение в IndexedDB (`review-v1-<id>`)
- P2P-синхронизация (Yjs по каналам данных WebRTC) и панель P2P: путь соединения (локальная сеть, напрямую, TURN), задержка, трафик
- Свой хостинг через `review-host`: интерфейс, хаб без состояния, поиск в локальной сети (mDNS)
- Десктоп-приложение (Tauri 2): хостит для друзей в вашей Wi‑Fi и хранит доски файлами
- Интерфейс на русском (по умолчанию), английском, китайском
- Оформление панелей и бумага доски — разные настройки

## Запуск

Нужен Node 20+.

```bash
npm install
npm run dev
```

Vite поднимает приложение на [http://localhost:5173](http://localhost:5173), а `review-host` (хаб) — на `:1234`. Откройте страницу. Нарисуйте. Обновите: доска на месте.

Два браузера (или устройство в LAN по вашему IP вместо `localhost`) на одном `/board/<id>` соединяются напрямую — доска идёт от браузера к браузеру.

Хостить по-настоящему (интерфейс и хаб на одном порту):

```bash
npm run host        # http://<lan-ip>:1234/
```

Десктоп: `npm run desktop` / `npm run desktop:build`, см. [docs/DESKTOP.md](docs/DESKTOP.md). Хостинг, Tailscale, VPS, STUN/TURN: [docs/DEPLOY.md](docs/DEPLOY.md).

`localhost` и `127.0.0.1` — разные origin. IndexedDB между ними не переезжает. Выберите одно.

```bash
npm test
npm run build
```

## Компоновка

Хром плавает над холстом на весь экран. Остров файла слева сверху (имя, отмена, зум). Присутствие и настройки справа сверху. Пояс инструментов снизу по центру. Остров стиля над поясом, когда живому инструменту или выделению это нужно. Связь и сохранение — в листе настроек.
