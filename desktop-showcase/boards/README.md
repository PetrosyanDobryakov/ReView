# boards — твои доски

Сюда клади `.review` файлы, чтобы не потерять и чтобы перенести на другой компьютер.

Как загрузить доску из этой папки в приложение:
1. Запусти приложение (`Start.bat` в корне showcase).
2. На главной: **Импорт** → выбери файл из этой папки.

Как сохранить доску сюда:
1. На доске: кнопка скачивания (или Главная → экспорт).
2. Сохрани файл в эту папку.

Подпапок можно делать сколько угодно (например, `boards/математика/`).
Файлы вида `*.review` больше 100 МБ сюда лучше не класть — такие доски
переносятся напрямую между устройствами (см. план в `docs/DESKTOP-PLAN.md`).
